Unzip this package. In GitHub, use Add file > Upload files and upload the five code files into the same folder as your existing app.py and history.json. Commit the changes; these files replace the previous versions. Do not change app.py or history.json. Streamlit runs app.py and rebuilds the website using your current data. If the update does not appear automatically, reboot the app from Manage app.
